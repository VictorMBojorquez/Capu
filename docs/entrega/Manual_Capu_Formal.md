## 1. Introducción

El presente manual describe el **Manual de Usuario** del sistema **CAPU**, desarrollado para la materia de Gestión de Proyectos de Software, cuyo objetivo es gestionar tareas académicas mediante recordatorios, seguimiento de avances y recompensas con tokens, integrándose con Google Classroom.

## 2. ¿Qué es CAPU?

Agenda inteligente con recordatorios y recompensas (tokens), integrada a Google Classroom.

## 3. Funcionalidades principales

- Agenda: tareas de Classroom, filtros por curso/estado, calendario.
- Sincronización: cursos, tareas y entregas desde Google Classroom (OAuth + PKCE).
- Entregas y tokens: registro de entregas, bonos, racha, recompensas.
- Alertas y recordatorios: vencidas, próximas (≤24 h), programados.
- Notificaciones: centro y preferencias.
- Documentación: esta guía con capturas.

## 6. Conclusión

El sistema CAPU permite gestionar tareas académicas, sincronizar con Google Classroom, registrar entregas con recompensas (tokens) y generar alertas/recordatorios, apoyado por una página de documentación con capturas.
